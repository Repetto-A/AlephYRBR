# Hackathon rules, schedule, and judging

## Event snapshot

- Dates: **August 22–23, 2026**
- Build window: Saturday Aug 22, 12:00 to Sunday Aug 23, 12:00 (Argentina time)
- Judging: Sunday Aug 23, approximately 13:00–17:00
- Closing ceremony: Sunday at 17:00
- Format: online and IRL across 11 chapters
- Team size: **1–4 people**
- Total prize pool: **$5,500**

## Non-negotiable rules

- Planning beforehand is allowed, but **all project code must be written and committed during the official hackathon window**.
- Code committed before the start or after the deadline can disqualify the project.
- You cannot use another team's code.
- Sponsor-specific requirements override generic assumptions; read the chosen track before building.

## Minimum submission

- A public open-source repository.
- A short README explaining the project and setup.
- A **3-minute recorded demo**; judging is asynchronous.
- If contracts are deployed, include contract addresses.
- Select the relevant tracks/bounties during submission and explicitly explain which requirements were satisfied.
- Each specialized track additionally asks for evidence such as integration permalinks, package versions, environment details, or an installable `pear://` link.

## Global judging criteria

1. **Technicality** — real technical challenge, sound engineering, completeness.
2. **Originality** — a specific pain point and a differentiated approach.
3. **UI/UX/DX** — intuitive for users or developers.
4. **Practicality** — feasible and useful beyond the demo.
5. **Presentation** — a clear story, working demo, and good supporting material.

## Implications for project strategy

- Design the **demo path first**. A working 3-minute vertical slice beats a broad unfinished platform.
- Make the sponsor technology indispensable to the product's core value.
- Prepare explicit evidence: exact files/lines, test results, failure cases, clean-clone setup, and environment data.
- Allocate time for README, recording, and submission; the coding deadline is also the submission deadline.
